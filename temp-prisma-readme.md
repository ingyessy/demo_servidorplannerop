# Capa de Acceso a Datos (Prisma)

## Descripción

Servicios y configuraciones para interactuar con la base de datos mediante el ORM Prisma.

## Funcionalidades

- Conexión y configuración de la base de datos
- Migraciones y semillas de datos
- Servicios de acceso a datos

## Clases y Componentes

### Servicios

Los servicios contienen la lógica de negocio y son utilizados por los controladores.

- **Prismaservice**: Implementa la lógica para gestionar prisma.

### Módulos

Los módulos agrupan componentes relacionados en un mismo contexto.

- **Prismamodule**: Organiza y configura los componentes relacionados con prisma.
